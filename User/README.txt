--------------------------------------------------------------------------------
1. 项目概述
--------------------------------------------------------------------------------
基于 STM32F103C8T6 的双轴云台控制系统，外接按键×1、LED×3、OLED、
SG90 舵机×2、MPU6050、四光敏矩阵，通过串口与 PC 通信。
单按键循环切换三种模式，上电默认模式一：

  模式一：串口指令操控（YAW/PITCH）
  模式二：MPU6050 姿态随动
  模式三：四光敏自动追光

2. 引脚分配
--------------------------------------------------------------------------------
功能                引脚          外设            备注
--------------------------------------------------------------------------------
LED1                PA5           GPIO 输出       低电平点亮，串限流电阻
LED2                PA6           GPIO 输出       低电平点亮，串限流电阻
LED3                PA7           GPIO 输出       低电平点亮，串限流电阻
按键                PA0           GPIO 输入       上拉，按下低电平
串口 TX             PA9           USART1_TX       115200-8-N-1
串口 RX             PA10          USART1_RX       接收中断 + 环形缓冲
I2C SCL             PB6           I2C1_SCL        400kHz，模块自带 4.7K 上拉
I2C SDA             PB7           I2C1_SDA        400kHz，模块自带 4.7K 上拉
PWM YAW             PA8           TIM1_CH1        20ms 周期，0.5~2.5ms 脉宽
PWM PITCH           PA11          TIM1_CH4        20ms 周期，0.5~2.5ms 脉宽
光敏 ADC [0]        PA1           ADC1_IN1        扫描 + DMA，对应光敏 A2（右）
光敏 ADC [1]        PA2           ADC1_IN2        扫描 + DMA，对应光敏 A4（左）
光敏 ADC [2]        PA3           ADC1_IN3        扫描 + DMA，对应光敏 A1（上）
光敏 ADC [3]        PA4           ADC1_IN4        扫描 + DMA，对应光敏 A3（下）
SWD                 PA13/PA14     SWDIO/SWCLK     调试口，保留

注：
1. PA13/PA14 保留 SWD 调试，不可复用。
2. 舵机独立 5V/1A 供电并与主控共地。
3. 光敏模块 VCC 接 3.3V（不要接 5V）。
4. MPU6050 的 AD0 必须接 GND（地址 0x68）。
5. ★ 光敏四路必须【对面配对】：A2-A4 一对、A1-A3 一对，
   否则两个轴会耦合，云台表现为绕圈。改接线需同步改 track.h 下标宏。
6. PCB 绘制所需的完整接口分配、连接器定义与布线注意事项，
   见 装配指南/PCB绘制参考.md。

6. 任务与文件对应
================================================================================
任务一：LED 自检、按键长短按、模式切换
        主要文件：bsp_gpio、key、led、app_mode

任务二：串口协议、OLED、事件回传
        主要文件：bsp_uart、dev_oled、protocol、oled_ui、uart_event、ring_buffer

任务三：双轴 PWM、YAW/PITCH 指令、回中位
        主要文件：bsp_pwm、dev_servo、gimbal、protocol

任务四：MPU6050 姿态解算、模式二随动
        主要文件：bsp_i2c、dev_mpu6050、attitude、filter

任务五：四光敏 ADC、追光、三模式联调
        主要文件：bsp_adc、track、app_task

各任务逐级叠加，低级功能在高级任务中不回退。


================================================================================
7. 串口通信协议
================================================================================
115200-8-N-1，每帧一行 ASCII，\r\n 或 \n 结束，≤32 字符。
命令与参数以单空格分隔，大小写不敏感。

指令                应答                说明
--------------------------------------------------------------------------------
AT                  OK                  握手
STATUS              OK MODE=<n>         查询模式（1/2/3）
YAW <a>             OK / ERR            仅模式一，a∈[0,180]
PITCH <a>           OK / ERR            仅模式一，a∈[0,180]
CAL                 OK / ERRCAL         模式二姿态零位校准
非法/越界/跨模式      ERR                 不执行动作

事件回传：短按 KEY S，长按 KEY L，模式改变 MODE<n>。
LED3 每收到一帧完整指令翻转一次。


================================================================================
8. 关键实现要点与可调参数
================================================================================
按键   ：松手判定，<50ms 抖动忽略；50ms~1s 短按（下一模式）；
         ≥1s 长按（上一模式），只计一次。

舵机   ：TIM1，PSC=71 → 计数频率 1MHz；ARR=19999 → 周期 20ms。
         比较值直接等于脉宽微秒数，0.5~2.5ms 对应 0°~180°，90° 中位。

姿态   ：MPU6050 原始数据经互补滤波融合，上电自动校准，CAL 可重新校准。
         陀螺仪量程 ±2000°/s（16.4 LSB/(°/s)），加速度计 ±2g（16384 LSB/g）。
         互补滤波系数当前为 0.72（可调，越大越平滑但越慢）。

追光   ：四路 ADC 滑动平均后，以左右/上下差值相对关系判别方位，
         使用相对容差，无固定绝对阈值；左右对应方位轴、上下对应俯仰轴。
         方向系数、容差、步进增益均为可调参数，见 track.c 顶部。

模式切换：app_mode_set() 统一处理，进入模式一即回中位，
         模式二即随动，模式三即追光。

任务周期（app_task.c 顶部宏定义，均可调）：
         按键扫描 10ms  |  LED 更新 50ms  |  OLED 刷新 100ms
         舵机与姿态 20ms |  追光 10ms

9. 编译与调试提醒
================================================================================
1. 在 CubeIDE 的 Include paths 中添加：
   User/Bsp、User/Device、User/Logic、User/App、User/Utils
2. main.c 只保留 CubeMX 初始化与 app_task_run() 调用。
3. 所有自建文件放在 User/ 下，避免 CubeMX 重新生成时覆盖。
4. 串口助手发送 AT 应回复 OK；短按/长按观察 OLED 与 LED2。
5. 舵机供电务必独立，防止复位与串口丢数据。
6. MPU6050 的 AD0 必须接 GND（地址 0x68），否则初始化失败。
7. 光敏模块 VCC 接 3.3V，不要接 5V。
